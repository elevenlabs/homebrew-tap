# ElevenLabs Homebrew Tap

Homebrew formulae for the [ElevenLabs CLI](https://github.com/elevenlabs/cli).

## Install

```sh
brew install elevenlabs/tap/elevenlabs
```

Or tap first, then install:

```sh
brew tap elevenlabs/tap
brew install elevenlabs
```

---

> This repository is maintained automatically by the ElevenLabs CLI release
> pipeline. The formula is generated and updated on each release — please do not
> edit it by hand.
